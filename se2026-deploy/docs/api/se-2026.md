# API Reference — SE 2026

Portal Sensus Ekonomi 2026 BPS Kabupaten Musi Rawas menyediakan **3 tier API**:

| Tier | Path | Auth | Tujuan |
|------|------|------|--------|
| Public | `/api/se/2026/public/*` | tanpa token | Frontend web, widget eksternal, BI read-only |
| External | `/api/se/2026/external/*` | Bearer token | Bot Fasih, aplikasi pihak ke-3 yang update data |
| Admin | `/api/admin/*` | Session login | UI dashboard internal (browser cookie) |

## Defense-in-depth multi-sensus

Token diterbitkan untuk **(sensus_kode, tahun)** yang spesifik. Token `se2026_*` **tidak bisa** dipakai untuk update SP 2030 atau ST 2033 — server memvalidasi path URL match dengan token-nya. Saat sensus baru mulai (SP 2030, ST 2033), masing-masing punya admin & token-nya sendiri yang terisolasi.

## Endpoints

### `GET /api/se/2026/public/progress?skala=UMK|UM|UB`

Anonymous read. Aggregate progress per kecamatan.

**Response 200**
```json
{
  "data": [
    {
      "kdkec": "1605030",
      "nmkec": "Muara Beliti",
      "target_usaha": 1240,
      "realisasi": 455,
      "persentase": 36.7,
      "petugas_count": 3,
      "breakdown": {
        "UMK": { "target": 850, "realisasi": 320, "persentase": 37.6 },
        "UM":  { "target": 280, "realisasi": 95,  "persentase": 33.9 },
        "UB":  { "target": 110, "realisasi": 40,  "persentase": 36.4 }
      }
    }
  ]
}
```

Saat `skala` dikirim (UMK/UM/UB), `breakdown` = `null`.

Cache: 60 detik.

### `GET /api/se/2026/public/stats`

Anonymous read. KPI dashboard.

### `POST /api/se/2026/external/progress`

Update progress via bearer token.

**Header**
```
Authorization: Bearer <token>
Content-Type: application/json
```

**Body**
```json
{
  "rows": [
    {
      "idsbr": "1620301234",
      "status": "selesai",
      "tanggal_cacah": "2026-05-30",
      "petugas_nip": "199001012015011001",
      "catatan": "Pencacahan lengkap",
      "lat": -3.0123,
      "lng": 102.9456
    }
  ]
}
```

Max 1000 rows per request. Rate limit 60 req/menit per token.

**Response 200**
```json
{
  "batchId": 42,
  "total": 1,
  "updated": 1,
  "errors": []
}
```

**Errors**
- `401` — Token tidak valid / kadaluarsa / di-revoke
- `403` — Token tidak punya akses ke SE 2026 (misal token SP/ST)
- `403` — Scope tidak cukup (butuh `write:progress`)
- `429` — Rate limit exceeded
- `400` — Body tidak valid

## Scopes

| Scope | Akses |
|-------|-------|
| `read:progress`  | GET data agregat progress |
| `write:progress` | POST update progress (implies read) |
| `read:usaha`     | GET daftar usaha |
| `write:usaha`    | POST/PATCH usaha (implies read) |
| `read:tahapan`   | GET tahapan & akses lanjutan |

## Contoh: Bot Fasih (Python)

```python
import requests

TOKEN = "se2026_xYzA_aBcDeF..."  # disimpan di env var, jangan commit

resp = requests.post(
    "https://sensus.bpskabmusirawas.com/api/se/2026/external/progress",
    headers={"Authorization": f"Bearer {TOKEN}"},
    json={"rows": [
        {"idsbr": "1620301234", "status": "selesai", "tanggal_cacah": "2026-05-30"},
        {"idsbr": "1620301235", "status": "proses"},
    ]}
)
print(resp.status_code, resp.json())
```

## Audit log

Setiap request external (atau anonymous public) dicatat di tabel `api_audit_log` (token_id, sensus, method, path, status, ip, ua, duration_ms). Admin bisa cek di dashboard.

## Token management

Token dibuat di dashboard: **/se/2026/dashboard/api**. Plaintext token hanya ditampilkan **sekali** saat dibuat — admin harus copy ke tempat aman saat itu. Untuk revoke: tombol "Revoke" di list — request berikutnya pakai token tsb akan 401.

## Catatan untuk sensus baru (SP 2030, ST 2033)

Tiap sensus akan dapat namespace API sendiri:
- `/api/sp/2030/external/*`
- `/api/st/2033/external/*`

Token tidak bisa berpindah sensus. Bot yang perlu akses multi-sensus harus pakai 1 token per sensus.

## Ingestion Progress Fasih (bot scraper)

Untuk update progress **otomatis & berkala** dari bot scraper Fasih. Data ini **agregat per wilayah & petugas** (bukan per-IDSBR).

### `POST /api/se/2026/external/fasih`  (JSON — direkomendasikan, tercepat)

Header: `Authorization: Bearer <token>` (scope `write:progress`), `Content-Type: application/json` (boleh `Content-Encoding: gzip`).

Body — semua level **opsional**, kirim yang berubah saja. Nama field per baris mengikuti kolom scraper (snake_case; header Excel ber-spasi juga diterima):

```json
{
  "snapshot_ts": "20260617_0500",
  "kecamatan": [
    { "kode_kec": "1605030", "total": 11157, "open": 10884, "draft": 55,
      "submitted_pencacah": 144, "submitted_responden": 0, "approved": 44,
      "rejected": 30, "revoked": 0, "selesai_cacah": 218, "selesai_approve": 44,
      "pct_cacah": 1.95, "pct_approve": 0.39 }
  ],
  "desa":  [ { "kode_kec": "1605030", "kode_desa": "1605030003", "total": 624, "selesai_cacah": 8, "...": "..." } ],
  "sls":   [ { "kode_kec": "1605030", "kode_desa": "1605030003", "kode_sls": "16050300030002", "total": 195, "selesai_cacah": 8, "...": "..." } ],
  "subsls":[ { "kode_kec": "1605060", "kode_desa": "1605060013", "kode_sls": "16050600130001",
              "kode_terkecil": "16050600130001", "nama_desa": "NGESTIKARYA", "nama_sls": "DUSUN 1",
              "pencacah": "ppl@gmail.com", "nama_ppl": "Nama PPL", "pengawas": "pml@gmail.com", "nama_pml": "Nama PML",
              "total": 151, "selesai_cacah": 0, "...": "..." } ],
  "petugas":[ { "pencacah": "ppl@gmail.com", "nama_ppl": "Nama PPL", "nama_pml": "Nama PML",
               "jumlah_unit": 409, "target": 409, "selesai_cacah": 0, "selesai_approve": 0,
               "pct_cacah": 0, "pct_approve": 0, "...": "..." } ],
  "pengawas":[ { "pengawas": "pml@gmail.com", "nama_pml": "Nama PML", "jumlah_ppl": 2,
                "jumlah_unit": 7, "target": 805, "selesai_cacah": 0, "selesai_approve": 0 } ]
}
```

Idempotent — upsert by PK tiap level (kode_kec / kode_desa / kode_sls / kode_terkecil / pencacah / pengawas). Kirim ulang = update, tidak menggandakan. Max ~6000 baris/request (pecah per level kalau lebih).

Response: `{ "ok": true, "snapshot_id": 12, "counts": { "kecamatan": 16, "desa": 200, "sls": 1280, ... }, "duration_ms": 230 }`.

#### Contoh `curl`
```bash
curl -X POST https://sensus.bpskabmusirawas.com/api/se/2026/external/fasih \
  -H "Authorization: Bearer se2026_xxx_xxxxxxxx" \
  -H "Content-Type: application/json" \
  --data-binary @payload.json
```

#### Contoh Python (langsung dari DataFrame scraper — minim delay)
```python
import requests, gzip, json

payload = {
    "snapshot_ts": ts,                               # "20260617_0500"
    "kecamatan": df_kec.to_dict(orient="records"),   # rename kolom ke snake_case opsional
    "desa":      df_desa.to_dict(orient="records"),
    "sls":       df_sls.to_dict(orient="records"),
    "subsls":    df_subsls.to_dict(orient="records"),
    "petugas":   df_petugas.to_dict(orient="records"),
    "pengawas":  df_pengawas.to_dict(orient="records"),
}
body = gzip.compress(json.dumps(payload).encode())
r = requests.post(
    "https://sensus.bpskabmusirawas.com/api/se/2026/external/fasih",
    headers={"Authorization": f"Bearer {TOKEN}",
             "Content-Type": "application/json",
             "Content-Encoding": "gzip"},
    data=body, timeout=60)
print(r.json())
```

> **Kolom dengan spasi** dari Excel (`"SUBMITTED BY Pencacah"`, `"APPROVED BY Pengawas"`, dll) tetap diterima apa adanya — tidak wajib di-rename. Tapi disarankan kirim snake_case (`submitted_pencacah`, `approved`, ...) biar payload lebih ringkas.

### `POST /api/admin/import/fasih`  (Excel — fallback manual)

Upload file `progres_subsls_*.xlsx` lewat dashboard **Import Data → tab "Progress Fasih (Scraper)"**. Server membaca 6 sheet (Rekap Kecamatan/Desa/SLS, Detail SUBSLS, Progress Petugas/Pengawas) → logika ingest sama dengan endpoint JSON. Cocok untuk update sesekali / manual; untuk update tiap menit pakai endpoint JSON di atas (lebih cepat, tanpa file).

### Metrik

`% progress publik = selesai_cacah / total` (submitted pencacah). `selesai_approve` (approved pengawas) disimpan & ditampilkan terpisah di tooltip + dashboard. Peta mewarnai kecamatan/desa/SLS berdasar `pct_cacah`.
