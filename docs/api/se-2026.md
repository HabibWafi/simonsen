# API Reference — SE 2026

Portal Sensus Ekonomi 2026 BPS Kabupaten Musi Rawas menyediakan **3 tier API**:

| Tier | Path | Auth | Tujuan |
|------|------|------|--------|
| Public | `/api/se/2026/public/*` | tanpa token | Frontend web, widget eksternal, BI read-only |
| External | `/api/se/2026/external/*` | Bearer token | Bot Fasih, aplikasi pihak ke-3 yang update data |
| Admin | `/api/admin/*` | Session login | UI dashboard internal (browser cookie) |

## Defense-in-depth multi-sensus

Token diterbitkan untuk **(sensus_kode, tahun)** yang spesifik. Token `se2026_*` **tidak bisa** dipakai untuk update SP 2030 atau ST 2033 — server memvalidasi path URL match dengan token-nya. Saat sensus baru mulai (SP 2030, ST 2033), masing-masing punya admin & token-nya sendiri yang terisolasi.

## Endpoints

### `GET /api/se/2026/public/progress?skala=UMK|UM|UB`

Anonymous read. Aggregate progress per kecamatan.

**Response 200**
```json
{
  "data": [
    {
      "kdkec": "1605030",
      "nmkec": "Muara Beliti",
      "target_usaha": 1240,
      "realisasi": 455,
      "persentase": 36.7,
      "petugas_count": 3,
      "breakdown": {
        "UMK": { "target": 850, "realisasi": 320, "persentase": 37.6 },
        "UM":  { "target": 280, "realisasi": 95,  "persentase": 33.9 },
        "UB":  { "target": 110, "realisasi": 40,  "persentase": 36.4 }
      }
    }
  ]
}
```

Saat `skala` dikirim (UMK/UM/UB), `breakdown` = `null`.

Cache: 60 detik.

### `GET /api/se/2026/public/stats`

Anonymous read. KPI dashboard.

### `POST /api/se/2026/external/progress`

Update progress via bearer token.

**Header**
```
Authorization: Bearer <token>
Content-Type: application/json
```

**Body**
```json
{
  "rows": [
    {
      "idsbr": "1620301234",
      "status": "selesai",
      "tanggal_cacah": "2026-05-30",
      "petugas_nip": "199001012015011001",
      "catatan": "Pencacahan lengkap",
      "lat": -3.0123,
      "lng": 102.9456
    }
  ]
}
```

Max 1000 rows per request. Rate limit 60 req/menit per token.

**Response 200**
```json
{
  "batchId": 42,
  "total": 1,
  "updated": 1,
  "errors": []
}
```

**Errors**
- `401` — Token tidak valid / kadaluarsa / di-revoke
- `403` — Token tidak punya akses ke SE 2026 (misal token SP/ST)
- `403` — Scope tidak cukup (butuh `write:progress`)
- `429` — Rate limit exceeded
- `400` — Body tidak valid

## Scopes

| Scope | Akses |
|-------|-------|
| `read:progress`  | GET data agregat progress |
| `write:progress` | POST update progress (implies read) |
| `read:usaha`     | GET daftar usaha |
| `write:usaha`    | POST/PATCH usaha (implies read) |
| `read:tahapan`   | GET tahapan & akses lanjutan |

## Contoh: Bot Fasih (Python)

```python
import requests

TOKEN = "se2026_xYzA_aBcDeF..."  # disimpan di env var, jangan commit

resp = requests.post(
    "https://sensus.bpskabmusirawas.com/api/se/2026/external/progress",
    headers={"Authorization": f"Bearer {TOKEN}"},
    json={"rows": [
        {"idsbr": "1620301234", "status": "selesai", "tanggal_cacah": "2026-05-30"},
        {"idsbr": "1620301235", "status": "proses"},
    ]}
)
print(resp.status_code, resp.json())
```

## Audit log

Setiap request external (atau anonymous public) dicatat di tabel `api_audit_log` (token_id, sensus, method, path, status, ip, ua, duration_ms). Admin bisa cek di dashboard.

## Token management

Token dibuat di dashboard: **/se/2026/dashboard/api**. Plaintext token hanya ditampilkan **sekali** saat dibuat — admin harus copy ke tempat aman saat itu. Untuk revoke: tombol "Revoke" di list — request berikutnya pakai token tsb akan 401.

## Catatan untuk sensus baru (SP 2030, ST 2033)

Tiap sensus akan dapat namespace API sendiri:
- `/api/sp/2030/external/*`
- `/api/st/2033/external/*`

Token tidak bisa berpindah sensus. Bot yang perlu akses multi-sensus harus pakai 1 token per sensus.
